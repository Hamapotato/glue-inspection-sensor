# 旧论文算法实现归档

本目录保存 2026-11-21 之前按学位论文拆分的旧算法路线。归档代码不参与当前
`algo/` 主包、默认配置、可执行入口和单元测试。

## 归档原因

旧路线包含多套并列方法：

- RPN RoI 定位与 K-means anchor；
- YOLOv3-5FL + SPP 反光检测；
- 小波去噪、Otsu/双峰/全局阈值分割；
- BFS 面积、Zhang-Suen 骨架、面积除以骨架长度的平均宽度；
- 五类旧合成样本和论文指标对照脚本。

当前主线改为：

```text
胶条/背景分割模型
  -> 概率图二值化与形态学后处理
  -> 沿胶条方向生成旋转扫描矩形
  -> 每个扫描矩形内定位左右边缘点
  -> 左右边缘点中点形成实际中心曲线
  -> 断胶、宽窄不一致、弯曲判定
```

## 使用边界

- 归档文件只用于追溯历史实现和对照论文；
- 归档源码与当时的主包相对导入绑定，不保证能在当前仓库直接独立运行；
- 不得从主包导入归档模块；
- 归档测试不属于当前测试门禁；
- 如确需恢复某段旧算法，必须先说明它与当前主线的接口和共存关系。
