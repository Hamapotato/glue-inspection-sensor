# P0 规范：主线指标、数据与假设

## 1. 指标定义

主线指标分为分割、扫描量测和质量判定三组。所有合成数据结果必须标记
`acceptance_eligible=false`，不能代替真实数据指标。

### 1.1 分割指标

| ID | 指标 | 定义 |
|---|---|---|
| S1 | 胶条像素 IoU | 测试集逐图像计算 `TP / (TP + FP + FN)`，再报告均值 |
| S2 | 胶条像素召回率 | `TP / (TP + FN)` |
| S3 | 胶条像素精确率 | `TP / (TP + FP)` |
| S4 | 边界误差 | 预测胶条边界到人工边界的最小距离统计，单位 px |

分割验收必须使用与模型输入完全一致的预处理、分辨率、阈值和后处理。

### 1.2 扫描量测指标

| ID | 指标 | 定义 |
|---|---|---|
| M1 | 胶宽 MAE | 扫描窗宽度与人工卡尺宽度的平均绝对误差 |
| M2 | 胶宽误差标准差 | M1 误差的总体标准差 |
| M3 | 胶宽最大误差 | M1 误差绝对值的最大值 |
| M4 | 宽度重复性 | 同一位置连续采集多帧的宽度标准差 |
| M5 | 中心线偏差 | 实际中心线相对人工或理论中心线的垂距 |
| M6 | 扫描量测耗时 | 分割后二值化、扫描、边缘和曲线统计耗时 |

胶宽真值必须来自人工卡尺或经确认的测量工具，不能使用理论宽度代替。

### 1.3 判定指标

| ID | 指标 | 定义 |
|---|---|---|
| Q1 | 断胶样本召回 | 断胶测试样本中被判为 `BROKEN` 的比例 |
| Q2 | 宽窄样本召回 | 过窄/过宽样本命中对应判定的比例 |
| Q3 | 宽窄不一致召回 | 沿程宽度异常样本命中 `WIDTH_UNSTABLE` 的比例 |
| Q4 | 弯曲召回 | 弯曲样本命中 `BENT` 的比例 |
| Q5 | 正常样本误报率 | 正常样本被判为任一缺陷的比例 |
| Q6 | 端到端耗时 | 图像输入到判定输出的 p50/p95 |

## 2. 数据规范

### 2.1 分割标签

- 类别固定为 `background=0`、`glue=1`；
- 标签为与图像同尺寸的单通道 PNG；
- 胶条前景为 255，背景为 0；
- 断胶处必须保持背景，不得为了形成连续条带而补洞；
- 宽窄和弯曲是几何场景属性，不新增类别。

### 2.2 数据划分

- 按工件、批次或采集对象分组划分；
- 同一工件的连续帧只能进入训练、验证或测试中的一个集合；
- 测试集冻结后不得根据模型结果调整；
- 合成数据只用于预训练、流程验证和冒烟。

建议比例：

```text
train : val : test = 70 : 15 : 15
```

## 3. 扫描窗规则

每个扫描窗必须满足：

1. 长边沿局部涂胶切线；
2. 短边沿胶条法向；
3. 横向宽度至少为实测胶宽的 3 倍；
4. 窗口边界不能作为胶条边缘；
5. 左右边缘必须来自窗口内的分割掩膜。

断胶判定：

- 缺少左侧或右侧任一边缘点：该窗口无效；
- 连续无效窗口数达到配置阈值：判 `BROKEN`；
- 当前原型阈值为 1，真实数据阶段必须重新评估误报率。

## 4. 假设登记

| 编号 | 项目 | 当前值 | 说明 |
|---|---|---|---|
| A1 | 分割模型架构 | 待定 | 当前只冻结接口，未冻结网络 |
| A2 | 输入分辨率 | 1440×1080 原图 | 按首台相机基线 |
| A3 | 分割阈值 | 0.5 | 概率图二值化初值 |
| A4 | 形态学核 | 5×5，先开后闭 | 去除分割噪点并补小孔 |
| A5 | 扫描窗横向比例 | 3.0 倍胶宽 | 用户要求的最小横向搜索范围 |
| A6 | 扫描步距 | 12 px | 当前合成配置初值 |
| A7 | 扫描窗长 | 24 px | 当前合成配置初值 |
| A8 | 法向最大搜索距离 | 180 px | 当前合成配置初值 |
| A9 | 断胶最小连续窗 | 1 | 原型规则，真实数据待调 |
| A10 | 标准胶宽 | 10 mm | 论文表 5-4 的理论宽度 |
| A11 | 宽度预警/报警 | ±0.5 / ±1.0 mm | 双报警线初值 |
| A12 | 沿程宽度极差报警 | 1.2 mm | 宽窄不一致初值 |
| A13 | 沿程宽度标准差报警 | 0.30 mm | 宽窄不一致初值 |
| A14 | 弯曲预警/报警 | 2.0 / 3.0 mm | 首尾弦线最大垂距 |
| A15 | 像素尺度 | 未标定 | 必须由单相机标定得到 |

以上参数中，扫描窗、阈值和报警线都不是论文给定值，必须通过真实数据验证。
