# M06 同轨迹验证数据集

> 状态：已生成 `glue-m06-matched-v1-100`，等待 VisionMaster M06 实机运行。
> 用途：验证 `边缘对模型缺陷检测` 在同一示教轨迹下的断胶、宽窄和弯曲判定。
> 边界：合成数据只用于流程验证，`acceptance_eligible=false`，不能代替真实数据验收。

## 1. 为什么需要同轨迹

上一版 500 张训练数据故意包含不同位置、角度和弯曲程度，目的是让
`background/glue` 分割模型不依赖固定胶路。

M06 的判定方式不同：它先在一张标准好品上建立固定示教轨迹，再把后续图像
与该标准轨迹比较。如果测试图本身使用另一条轨迹，M06 会先产生位置缺陷，
无法区分“轨迹不同”和“胶条弯曲异常”。

因此本数据集满足：

- 所有图像共用 `m06_fixed_path_v1`；
- 图像尺寸、背景类型和胶条外观与现有合成训练数据一致；
- 每次只改变一个目标因素；
- 附正常控制图，用于统计正常样本误报。

## 3. 缺陷生成规则

| 场景 | 相对标准模板的改动 |
|---|---|
| 正常 | 轨迹和基准宽度不变，仅改变背景纹理、亮度、模糊和噪声 |
| 断胶 | 在轨迹中部切除 60～120 px，保持真实断口 |
| 过窄 | 整体宽度缩放为基准宽度的 52%～64% |
| 过宽 | 整体宽度缩放为基准宽度的 136%～150% |
| 弯曲 | 保持基准宽度，在局部段沿法向平滑偏移 26～38 px |

宽度缩放值和弯曲幅值来自 `configs/default.yaml` 的 `m06_validation` 段。
这些是合成验证参数，不是产线业务阈值。

## 4. VisionMaster 中的用法

1. 先完成 DL 图像分割、二值化和形态学处理。
2. 用标准模板图在 M06 中生成固定轨迹和标准边缘对。
3. M06 的宽度合格比例先设为能明显区分正常、窄和宽的范围。
4. 开启宽度、位置偏移和断裂缺陷；首轮方案中气泡缺陷也有响应，但本 100 张
   数据集不包含独立气泡类别，不能据此统计气泡指标。
5. 先运行标准模板和正常控制图，要求 `OK` 且 `DefectType=()`。
6. 再运行异常图，检查是否命中对应 `DefectType`。
7. 需要实时查看图片和 OK/NG 时，按
   [VM 结果查看器](../../deployment/vm-viewer/README.md) 配置原图、卡尺图输出
   和 TCP 结果；逐类统计仍以冻结数据集记录为准。

建议按下面的数据顺序调试：

```text
标准模板
  -> 同轨迹正常
  -> 断胶
  -> 过窄
  -> 过宽
  -> 弯曲
```

## 5. 重新生成

```powershell
py -3 scripts/generate_m06_validation_dataset.py `
  --out outputs/m06-validation/glue-m06-matched-v1-100
```

同一配置和 seed 会生成完全相同的图像、掩膜和标签。输出目录必须为空，
新版本应使用新的目录名，避免覆盖已冻结的测试集。

## 6. 验收边界

本数据集可用于验证：

- M06 是否按同一示教轨迹布置卡尺；
- 断口是否仍保留在分割掩膜中；
- 宽度缺陷和位置偏移是否能被对应模块参数捕获；
- 正常控制图是否存在明显误报。

本数据集不能用于声明：

- 真实产线检出率；
- 真实相机宽度误差；
- 实际节拍；
- 最终误报率或漏报率；
- 气泡检出率或气泡误报率。
