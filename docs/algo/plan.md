### 0.2 三类"必须写清"的差异

1. **忠实实现**：C1–C7、B1 的结构、式 3-8~3-15、CIoU-NMS（阈值 0.5）、B2 的 5 层特征层 + SPP。
2. **允许替代**（论文未给，需在报告中注明假设）：backbone、优化器、学习率、anchor 尺度初值、小波基、开闭核尺寸、BFS 种子来源。
3. **无法复现**：原始数据集、原厂内参、随机种子、论文的具体训练轮数。

## 2. 模块实现方案

### 2.1 标定（C4）

- **输入**：棋盘格图像序列 + 方格物理尺寸。
- **流程**：`cv2.findChessboardCorners` → `cv2.calibrateCamera` → 内参 K、畸变 dist、重投影误差。
- **输出**：`CalibrationResult{K, dist, rms, per_view_errors}`；`mm_per_px`（工作距离处）与平面单应 `H`。
- **论文依据**：4.3.1 成像模型、4.3.2 标定验证（表 4-2 重投影误差）。
- **注意**：论文用"标定后的映射关系"求实际宽度，本质是平面尺度换算；本实现同时提供
  `mm_per_px` 常量与 `H` 单应两种映射，报告中说明用哪种。

### 2.2 预处理（C1–C3）

| 步骤 | 实现 | 论文依据 | 缺失项处理 |
|---|---|---|---|
| 去噪 | Haar 小波 2 层 + 通用阈值（`σ√(2lnN)`），硬阈值；同时保留中值滤波做对比 | 4.1.1 硬阈值、4.1.2 对比 | 小波基/层数论文未给 → 配置项 |
| 分割 | Otsu 为主，双峰法/全局阈值做对比 | 4.2.1 | — |
| 形态学 | 开运算去小噪点 + 闭运算补孔洞 | 4.2.2 | 核尺寸论文未给 → 配置项 |

### 2.3 量测（C5–C7）

1. **面积**
   - `bfs_area(mask, seeds)`：从种子点（论文的"深度学习置信点"，图 4-20）出发 8 邻域 BFS，
     统计连通域面积；
   - `contour_area(mask)`：外轮廓法（`cv2.findContours` + `contourArea`），用于和 BFS 对比（表 4-3、4-4）。
2. **骨架**：Zhang-Suen 细化（文献 [53]），输出单像素骨架；长度按 4/8 邻接加权。
3. **宽度**：`width_px = area_px / length_px`（论文 4.4.3），再乘标定映射得 mm。
   - 前提：胶条平均长度有限（论文第 6 章："平均在 50 mm 左右"），需在报告里写明适用边界。
4. **断胶**：不做像素级断口检测，按论文 5.3.3 —— **RoI 数量 > 1** 即判为断胶。

### 2.4 RoI 定位（B1）

| 组件 | 实现要点 | 论文依据 |
|---|---|---|
| 特征提取 | backbone 先用 ResNet-50（论文未指定），stride 16 | 3.1.1 特征图 |
| RPN | 3×3 卷积 → 两支 1×1（2k 分类 / 4k 回归），k=9 | 3.1.1、图 3-1 |
| 先验框 | 对训练集标注框 (w,h) 做 K-means（距离 1−IoU），k=9，替换通用 anchor | 3.1.2、图 3-2/3-6 |
| 回归损失 | DIoU（`L = 1 − DIoU`），并保留 GIoU/CIoU 分支用于消融 | 3.1.3、式 3-8~3-15 |
| 候选框筛选 | CIoU-NMS，阈值 0.5 | 3.1.4、表 3-2 |
| 输出 | 单类（胶条）Top-1 框 | — |

**消融要求**：必须能重跑出表 3-1（IoU/GIoU/DIoU/CIoU 的 IoU 与耗时）和表 3-2（NMS 与 CIoU-NMS 在不同阈值下的速度与 AP）。

### 2.5 反光检测（B2）

| 组件 | 实现要点 | 论文依据 |
|---|---|---|
| 基线 | YOLOv3（Darknet-53 + FPN 3 尺度） | 3.2、图 3-18 |
| 5 层特征 | 在 3 尺度基础上再上采样两级，输出 5 个尺度 | 3.3.2、图 3-20 |
| SPP | 4×4 / 2×2 / 1×1 最大池化，21 个 bin | 3.3.3、图 3-21 |
| 组合 | 5FL、SPP 分别验证，再组合（spp+5l） | 3.3.4、表 3-4 |
| 用途 | **只判"是否存在反光"并定位**，不修复 | 3.3.4、6.2 |

**消融要求**：能重跑表 3-4 的四组对比（YOLOv3 / -5l / -spp / -spp+5l 的逐图 IoU 与耗时）。

### 2.6 判定（D1）

```
if 反光判定为真 and 首轮判为缺陷:
    → REFLECTION_SUSPECT（提示"存在反光，请修正参数"，不计缺陷）
elif RoI 数量 >= 2:
    → BROKEN（断胶）
elif width < alarm_low:  → TOO_NARROW（过窄）
elif width > alarm_high: → TOO_WIDE（过宽）
elif width < warn_low / > warn_high: → WARN_*（双报警线）
else: → OK
```

论文的"双报警线"来自产品册（第 17 页），论文正文只给了"与标准数据库比对"，阈值必须可配置。

## 3. 数据方案（最大风险）

论文数据不公开，必须自建。**没有数据，B1/B2 无法复现，C1–C7 也无法出 0.23 mm。**

| 用途 | 规模（建议） | 标注 |
|---|---|---|
| RoI 定位 | 800–1200 张（多车型/多工位/多胶色） | 每图 1 个胶条框 |
| 反光检测 | ≥154 张（对齐论文 77 张的两倍） | 反光区域框（细长反光必须单独标） |
| 分割/量测 | 200–300 张 | 胶条掩膜（仅评估用） |
| 宽度真值 | 60+ 组 | 游标卡尺人工实测，记录测量人/工具 |
| 缺陷样本 | 断胶/过宽/过窄 各 ≥30 例 | 类别标签 + 掩膜 |

规则：

1. **按工件/批次划分**训练/测试集，不能按帧随机划分（同一条胶条的多帧会泄漏）；
2. 采集参数（曝光、增益、相机号、工作距离）写入 `manifest.csv`；
3. 合成数据只用于**冒烟测试与预训练**，验收一律用真实图；
4. 标注双人复核，反光框计算标注一致性（IoU）。

## 4. 评估协议

### 4.1 指标定义（必须先冻结，否则无法和论文对照）

| 论文说法 | 精确定义 | 注意事项 |
|---|---|---|
| 平均 IoU 99% | 测试集上 `mean IoU(预测 RoI, GT RoI)` | **不是 mAP**；表 5-2 的 AP 0.9951 不能当目标 |
| 75/77，97% | 77 张反光图的**样本级召回** | 不是像素 IoU；表 3-4 的 74–93% 是反光框 IoU |
| 0.23 / 0.25 / 0.39 mm | 计算宽度 vs **人工卡尺**的 MAE / std / max | 真值来自人工实测 |
| 80 ms / 30 fps | 单帧检测耗时（不含采集） | 需另报端到端耗时 |

### 4.2 必须能重跑的论文表格

| 论文表 | 复现内容 |
|---|---|
| 表 3-1 | 4 种 IoU 计算方式 → 定位 IoU 与检测耗时 |
| 表 3-2 | NMS vs CIoU-NMS × 阈值 0.5~0.9 → 速度与 AP |
| 表 3-4 | 4 种 YOLO 变体 → 逐图 IoU 与耗时 |
| 表 4-3 / 4-4 | BFS 与外轮廓法 → 面积与耗时 |
| 表 4-5 | 宽度计算值 vs 人工值 → 误差表 |

### 4.3 验收门（建议）

| 阶段 | 通过标准 |
|---|---|
| C 链路 | 宽度 MAE ≤ 0.4 mm、最大误差 ≤ 1.0 mm |
| B1 | 测试集平均 IoU ≥ 95%（目标 99%） |
| B2 | 反光样本召回 ≥ 95%（对齐 97%） |
| 集成 | 单帧 ≤ 33 ms（不含特殊复判），端到端 p95 ≤ 150 ms |

## 6. 风险与降级

| 风险 | 影响 | 对策 |
|---|---|---|
| 数据不足 | B1/B2 无法训练 | 先采 200 张做可行性；合成数据仅用于预训练 |
| 论文指标不可达 | 无法对齐 99%/97% | 报告写"同定义下 X%"+ 归因，不修改定义凑数 |
| 99% IoU 因数据简单而虚高 | 结论失真 | 测试集加入反光/阴影/断胶等困难样本 |
| 超参缺失 | 结果不稳 | 配置化 + 固定 seed + 实验日志 |
| 环境依赖 | torch 安装大 | 已有 Python 3.10/3.12/3.14；3.14 有 torch 2.15.0 轮子，建议独立 venv |
| 端到端 30 fps 达不到 | 集成验收失败 | 先测纯推理，再做模型裁剪/量化（对应论文 6.2 展望） |
