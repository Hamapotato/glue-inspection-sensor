# 涂胶检测主线方案

> 状态：2026-11-21 主线重构
> 核心方法：胶条分割模型 + 随胶条旋转的扫描矩形 + 边缘中点曲线
> 归档：旧 RPN、YOLO 反光、面积/骨架平均宽度等实现见
> [legacy-paper-algorithm](../../archive/legacy-paper-algorithm/README.md)

## 1. 主线目标

从单帧图像中完成以下闭环：

```text
胶条/背景分割模型
  -> 概率图或掩膜二值化
  -> 形态学后处理
  -> 沿涂胶方向生成旋转扫描矩形
  -> 每个矩形内寻找左右胶条边缘点
  -> 两个边缘点的中点形成实际中心曲线
  -> 判断断胶、过窄、过宽、宽窄不一致和弯曲
```

模型只负责像素级胶条分割，不直接输出缺陷。缺陷由扫描窗中的边缘点、
局部胶宽和中心曲线计算得到。

## 2. 分层架构

### 2.1 分割层

接口：`algo.segmentation.GlueSegmenter`

输入：

- 一帧原始图像；
- 或按实际部署方式裁剪后的模型 RoI。

输出：

- `background/glue` 概率图或二值掩膜；
- 模型来源信息。

当前代码定义接口、二值化、形态学后处理和外部函数适配器。VisionMaster 首轮
方案已配有一套 VM 440 CPU 胶条/背景分割模型，见
[M06 首轮部署包](../../deployment/visionmaster/glue_m06_inspection_v1/README.md)。
该模型目前只有首轮运行观察，尚无冻结测试指标。

### 2.2 扫描量测层

接口：`algo.scanline.scan_glue_strip`

1. 由分割掩膜提取胶条中心线；
2. 按整体涂胶方向排序，断口两侧按预期路径桥接；
3. 沿中心线等距放置扫描矩形；
4. 矩形方向随局部切线旋转；
5. 在矩形内沿法向定位左右边缘点；
6. 中点等于两个边缘点的几何中心。

扫描矩形横向宽度由配置决定，默认至少为实测胶宽的 3 倍。矩形边界仅是搜索范围，
不是胶条边界。

### 2.3 判定层

判定顺序：

1. 缺少左右边缘点对：断胶；
2. 平均宽度偏差：过窄或过宽；
3. 沿程宽度极差/标准差：宽窄不一致；
4. 中心线与允许轨迹或首尾弦线的偏差：弯曲。

### 2.4 部署实现优先级

量产运行优先采用纯 VisionMaster 方案：

```text
DL图像分割
  -> 胶条掩膜
  -> 形态学后处理
  -> 边缘对位置趋势分析（直线/轻微弯曲验证）
  -> 边缘对模型缺陷检测（固定曲线胶路主方案）
  -> VM 条件检测和逻辑
  -> OK/NG 与量测值
```

纯 VM 方案不再依赖外部 Python 进程。VM 内置脚本模块只用于统计数组结果，
不把模型推理和边缘量测移回外部程序。

结果展示通过独立前端完成：VM 将原图、卡尺检测图、OK/NG 和缺陷信息合并为
一个 TCP 二进制帧；前端在内存中解码和显示，OK 不落盘，仅 NG 保存历史。
前端不参与检测判定。
接口见 [interfaces.md](interfaces.md) §7，运行与验证见
[VM 结果查看器](../../deployment/vm-viewer/README.md)。

当前正式 `glue_m06_inspection_v1.sol` 是该路线第一版可运行方案，已包含
内存帧脚本、图形输出和 TCP 接线。用户人工观察已确认断胶、过宽、过窄和气泡
有响应，但尚未形成逐类统计和真实数据验收。

Python `algo.scanline` 主线继续作为：

- 合成数据算法基准；
- VisionMaster 结果的离线对照；
- 普通 VM 模块无法覆盖的复杂胶路后备方案。

详细配置见
[VisionMaster 纯 VM 主线](visionmaster-pure-vm-mainline.md)。

## 3. 模型训练数据

训练标签只有：

- `background=0`
- `glue=1`

断胶、过窄、过宽、宽窄不一致和弯曲是样本场景元数据，不是额外分割类别。

当前 `visiontrain-glue-binary-v5` 为合成数据，只用于：

- 训练流程验证；
- 预训练；
- 二值化、扫描窗和判定链路冒烟。

验收必须使用真实相机图像，并单独记录训练集、验证集和测试集划分。

## 4. 标定

所有内部几何计算使用像素。输出毫米宽度前必须完成单相机标定。

标定负责：

- 像素到毫米映射；
- 去畸变和固定工作平面映射；
- 中心、边缘和四角尺度误差验证。

没有标定时仍可输出扫描窗、像素宽度和曲线，但毫米宽度判定必须跳过并在结果中
记录降级原因。

## 5. 当前边界

- 已有一套首轮运行的合成数据分割模型，但尚未完成真实数据验证；
- 合成数据不能作为真实指标；
- 扫描窗参数和宽度报警线需要在真实相机图像上重新标定；
- 曲线目前由中点平滑折线表示，后续可增加样条拟合和理论轨迹偏差；
- 断胶当前允许“1 个扫描窗缺失边缘点”触发，真实数据联调时需要评估连续窗阈值。
