## 1. 目的与口径

对应论文 3.3 的反光检测模块，指标口径见 `p0-spec.md`：

- **M2 样本召回**：一张图至少一个预测框与真实框 IoU ≥ 0.5 即算检出；
- **M3 框 IoU**：预测反光框与真实框的最佳 IoU；
- 论文值：77 张反光样本检出 75 张（97%），测试集为作者自建真实图像。

## 4. 训练尝试与结果

在合成反光数据（48 训练 / 12 验证，128×128）上训练 5 层 + SPP：

| 轮次 | obj 损失 | cls 损失 | box 损失 | 验证召回 |
| --- | --- | --- | --- | --- |
| 1 | 1.88 | 0.04 | 0.45 | 0 |
| 5 | 0.001 | 0 | 0.44 | 0 |
| 16 | 0.0001 | 0 | 0.44 | 0 |

训练损失下降但**验证召回始终为 0**，模型学成"全图接近背景"的退化解。

### 失败原因分析

1. **目标尺度过小**：合成反光框在 128 输入下只有约 15×6 像素，而 /2 层最小 anchor 为 28×16，宽高 IoU 只有约 0.15；
2. **正样本占比极低**：5 层共 5460 个 anchor，每张图仅 1 个正样本，obj 损失被背景稀释（已改为按正样本数归一化 + pos_weight，仍不足）；
3. **合成数据反光位置固定**：反光总在胶条中心，模型找到"全背景"这一捷径即可降低大部分损失；
4. **输入分辨率不足**：论文在 1280×960 上检测，反光区域相对更大，本实验为控制 CPU 时间压到 128。

## 5. 与论文的差距

| 项目 | 论文 | 本仓库 |
| --- | --- | --- |
| 数据 | 真实反光图像 | 合成图像 |
| 输入 | 1280×960 | 128×128（CPU 限制） |
| 样本召回 | 97%（75/77） | 0（未收敛） |
| 四组消融（表 3-4） | 有 | 未完成（B-11） |

**结论：模块实现完成、训练闭环可用，但训练收敛依赖真实数据与更高分辨率输入；当前不产出任何可比指标。**

## 6. 下一步

1. 真实反光图像到位后，用 `--manifest/--labels` 重训，输入提到 320–416；
2. 用真实框做 K-means 生成 15 个 anchor（真实框尺度分布更广，聚类才有意义）；
3. 若仍不收敛，改用 focal loss 或按正样本数归一化 obj 损失（当前已按此方向处理，需真实数据验证）；
4. 输入分辨率提到 640 时，注意 CPU 训练成本，必要时上 GPU 或云训练。
