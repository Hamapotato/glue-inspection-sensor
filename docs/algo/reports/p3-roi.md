# P3 报告：RPN 胶条 RoI 定位（论文 3.1）

> 日期：2026-11-15 ｜ 代码：`algo/net/rpn.py`、`algo/models.py`、`scripts/train_rpn.py`
> **重要：本报告全部结果为合成数据冒烟，不是论文指标，不可与论文 99% 直接比较。**

## 1. 目的与口径

对应论文 3.1 的 RPN 定位模块，指标口径见 `p0-spec.md` M1：

- **M1 平均 IoU**：逐图计算预测框与真实框的最佳 IoU，再取算术平均——**不是 mAP**；
- 论文值：平均 IoU 99%，测试对象是作者自建的真实胶条图像集，本仓库没有该数据集。

## 2. 实现内容

| 项目 | 实现 | 论文位置 |
| --- | --- | --- |
| 骨干 | 4 次 stride=2 卷积 → stride 16，256 通道 + 3×3 卷积 | 3.1.1（论文未给骨干，假设 A6） |
| 双分支 | 1×1 分类头（9 通道）+ 1×1 回归头（36 通道） | 3.1.1 |
| 先验框 | 9 个，由训练集真实框 K-means 生成（`anchors_from_kmeans`） | 3.1.2 |
| 回归损失 | 1 − DIoU（可选 IoU/GIoU/CIoU） | 3.1.3 |
| 候选框筛选 | CIoU-NMS，阈值 0.5；另提供标准 NMS 对照 | 3.1.4、表 3-2 |
| 训练采样 | 每图 256 个 anchor，正样本占 50%，正样本按 IoU 排序取 | 论文未给细节 |

## 3. 数据与配置

- 数据：`algo/synth.generate_case` 合成五类用例（正常/过窄/过宽/断胶/反光），训练 48 张、验证 16 张，seed 分离；
- 输入：320×320（letterbox），灰度；
- 模型：`width=16`（骨干通道），约 17 万参数；
- 训练：AdamW，lr 1e-3 + 余弦退火，batch=1，60 epochs，CPU 约 1.5 s/epoch。

K-means 先验框（320 输入，宽×高，像素）：

```
(243.3, 31.3) (243.3, 31.3) (243.3, 31.3)
(246.0, 43.3) (246.0, 43.3) (254.0, 43.3)
(254.0, 43.3) (248.7, 55.3) (248.7, 55.3)
```

真实框宽高集中在 243–254 × 31–55，说明聚类结果与数据匹配。

## 4. 结果（合成数据）

| 指标 | 数值 |
| --- | --- |
| 最佳轮次 | 第 57 轮 |
| 验证集平均 IoU（M1） | **0.9781** |
| IoU ≥ 0.5 命中率 | **1.000**（16/16） |
| 首轮损失（cls / reg） | 0.236 / 1.012 |
| 末轮损失（cls / reg） | 0.0009 / 0.011 |
| 训练耗时 | 约 1.5 s/epoch（CPU，320 输入） |

损失从 1.25 单调降到 0.011，验证 IoU 从 0.59 升到 0.978 后进入平台，未见震荡或发散，训练链路可用。

## 5. NMS 对比（对应任务 B-04 / B-06）

对同一权重做 2 种筛选方式 × 3 个阈值：

| NMS 方式 | 阈值 0.3 | 阈值 0.5 | 阈值 0.7 |
| --- | --- | --- | --- |
| 标准 NMS | 0.9805 | 0.9805 | 0.9805 |
| CIoU-NMS | 0.9805 | 0.9805 | 0.9805 |

三种阈值下最佳框 IoU 完全一致，原因是模型收敛后 Top-1 候选框稳定，不同 NMS 只改变后续框的数量，不影响最佳匹配。**因此本表不能作为论文表 3-2 的复现结论**，该表需要真实数据上"候选框质量随阈值变化"才能复现。

## 7. 复现命令

```powershell
# 训练（合成冒烟）
.\.venv\Scripts\python.exe scripts\train_rpn.py --synthetic --img-size 320 --width 16 `
    --epochs 60 --lr 1e-3 --kmeans-anchors --out outputs/train_rpn

# 评估
.\.venv\Scripts\python.exe scripts\eval_rpn.py --weights outputs\train_rpn\best.pt `
    --synthetic --img-size 320 --nms ciou_nms --nms-thr 0.5
```

真实数据到位后：把 `--synthetic` 换成 `--manifest data/manifest.csv --labels data/labels/roi`，按 `p0-spec.md` 冻结测试集重训，才可填论文对照表。
