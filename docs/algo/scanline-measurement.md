# 旋转扫描矩形量测主线

> 状态：代码与合成掩膜验证完成；VM 首轮模型已部署，真实模型指标和真实图像待验证
> 实现：`algo/segmentation.py`、`algo/scanline.py`、`algo/pipeline.py`

## 1. 输入

输入必须是胶条/背景分割模型输出：

- 概率图；或
- 已经二值化的胶条掩膜。

流水线内部完成 `background/glue` 二值化和形态学后处理。旧的小波、Otsu 主链路
已归档，不属于当前算法。

## 2. 扫描矩形

1. 从分割掩膜提取胶条中心线；
2. 按整体涂胶方向排序；
3. 断口两侧按整体方向桥接，避免扫描序列在断口结束；
4. 沿中心线按步距放置矩形；
5. 矩形长边随局部切线旋转；
6. 矩形横向宽度默认至少为实测胶宽的 3 倍。

矩形边界只定义搜索范围。胶条边缘必须由矩形内部的掩膜确定。

## 3. 边缘点与中心点

每个扫描窗沿法向寻找两个点：

```text
left_i  = 左侧胶条边缘
right_i = 右侧胶条边缘
```

两个点都存在时：

```text
width_i  = distance(left_i, right_i)
center_i = (left_i + right_i) / 2
```

所有有效 `center_i` 按涂胶顺序连接，并在断口处分段和轻微平滑，得到实际中心线。

## 4. 断胶

- 缺少左侧或右侧任一边缘点：窗口无效；
- 连续无效窗口数达到 `break_min_missing_windows`：窗口标为断胶；
- 当前配置为 1 个窗口即报警。

该阈值适合原型冒烟。真实图像可能存在分割抖动，需要用实际数据评估连续 2～3 个
窗口是否更稳定。

## 5. 宽度与弯曲

每个有效扫描窗输出：

- 局部宽度；
- 左右边缘点；
- 中点；
- 窗口角度和尺寸。

汇总输出：

- 平均宽度；
- 最小/最大宽度；
- 宽度极差；
- 宽度标准差；
- 每个连续中心线段的弯曲量。

当前弯曲量采用中心线段相对首尾弦线的最大垂距。后续真实轨迹可用理论涂胶轨迹
代替首尾弦线。

## 6. 配置

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `step_px` | 12 | 相邻扫描窗中心距 |
| `window_length_px` | 24 | 沿胶条方向的窗口长度 |
| `window_width_factor` | 3.0 | 横向窗口宽度与实测胶宽比例 |
| `max_ray_px` | 180 | 法向边缘搜索最大半径 |
| `ray_step_px` | 0.5 | 法向采样间隔 |
| `break_min_missing_windows` | 1 | 断胶最小连续无效窗数 |
| `centerline_smooth_window` | 7 | 中心线平滑窗口 |

这些参数属于复现假设，必须由真实相机和已知尺寸试件重新确认。

## 7. 可视化

`scripts/make_scanline_overview.py` 从 v5 合成数据生成总览图：

- 蓝色矩形：有效扫描窗；
- 红色矩形：断胶窗；
- 绿色圆点：左右边缘点；
- 红色曲线：左右边缘点中点连线；
- 半透明绿色：分割掩膜。

输出：

```text
outputs/preview/scanline_v5_overview.png
```
