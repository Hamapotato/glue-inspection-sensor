# 单相机标定与尺寸验证计划

> 适用设备：HIKROBOT `MV-CB016-10UM-S` + 6 mm M12 镜头
> 制定日期：2026-11-15
> 当前阶段：第一台相机和 MVS 已就绪，开始 P1 真实数据验证
> 关联任务：`C-04` 相机标定、`A-06` 试标 20 张图、`C-07` 宽度误差验收

---

## 1. 本轮目标与边界

本轮先完成**单相机固定工位**的几何标定和尺寸验证，回答以下问题：

1. 当前相机、镜头、工作距离和 3D 打印支架能否稳定覆盖目标视野；
2. 能否获得可信的相机内参、畸变参数和像素到毫米的映射；
3. 胶条宽度的重复性和绝对误差是否接近项目要求；
4. 当前传统量测链路是否可以作为后续数据采集和算法迭代的基线。

本轮**不包含**：

- 三相机相对位姿标定；
- 三相机同步和机器人坐标标定；
- 红光频闪下的最终缺陷判定验收；
- 深度模型精度验收。

本轮的最终交付物是一套可复查的单相机标定结果、独立尺寸验证报告和固定采集参数。没有完成独立尺寸验证前，不能把标定得到的平均 `mm/px` 当作正式 P1 指标。

---

## 2. 总体流程

```text
打印并测量棋盘格
    -> 装配、调平、粗调工作距离
    -> 锁焦、锁光圈、固定曝光和增益
    -> 采集 25～30 张不同位姿的棋盘格图像
    -> 计算内参、畸变和重投影误差
    -> 使用未参与标定的图像做留出验证
    -> 使用已知宽度试件做物理尺寸验证
    -> 保存标定版本并冻结参数
```

3D 打印件负责重复定位，棋盘格提供真实物理尺寸，已知宽度试件负责最终验证。三者缺一不可，不能直接用打印件的设计高度或靶纸标称尺寸填写 `mm_per_px`。

---

## 3. 相机与视野基线

`MV-CB016-10UM-S` 的分辨率为 1440 x 1080，像元尺寸约 3.45 μm。按 6 mm 镜头和薄透镜模型估算：

| 镜头到目标物距 | 理论视野 | 理论采样尺度 |
|---:|---:|---:|
| 130 mm | 102.7 x 77.0 mm | 0.0713 mm/px |
| 135 mm | 106.8 x 80.1 mm | 0.0742 mm/px |
| 140 mm | 111.0 x 83.2 mm | 0.0771 mm/px |
| 145 mm | 115.1 x 86.3 mm | 0.0799 mm/px |

说明：

- 表中的物距是薄透镜估算值，实际应以图像中的视野和测量结果为准；
- 建议把 3D 打印支架的初始高度定在约 135 mm；
- 支架应允许在 125～150 mm 范围内调整，找到完整视野和最佳合焦位置后再锁紧；
- 相机到胶条上表面的实际距离必须记录，不能只记录打印件的设计尺寸。

## 4. 标定靶设计

### 4.1 必须使用棋盘格

OpenCV 的 `findChessboardCorners` 需要黑白交替的棋盘格，普通方格线纸不能满足标定要求。

第一版建议参数：

| 项目 | 取值 |
|---|---|
| 内角点数量 | 13 x 9 |
| 黑白方块数量 | 14 x 10 |
| 单个方格标称边长 | 7.0 mm |
| 棋盘格有效区域 | 约 98 x 70 mm |
| 外围白色边界 | 约 7 mm |
| 打印纸张 | A4 横向，300 dpi 以上 |
| 安装方式 | 粘接到 2～3 mm 平整亚克力、铝板或刚性板材 |

选择 7 mm 方格的原因：

- 13 x 9 内角点的有效角点跨度约为 91 x 63 mm；
- 在约 135 mm 工作距离下能覆盖 100 x 80 mm 目标的大部分视野；
- 方格投影约为 94～95 px，角点检测稳定性较好；
- 原有 13 x 9、4 mm 靶标的角点跨度只有约 52 x 36 mm，适合流程验证，但不适合作为全视野正式靶标。

### 4.2 打印和测量要求

1. 使用激光打印机或高精度喷墨打印；
2. 打印时选择“实际大小”，禁止选择“适应页面”；
3. 使用哑光纸，避免反光和墨水扩散；
4. 打印后粘接到刚性平板上，保证纸面不翘曲；
5. 打印件表面不能有气泡、褶皱和明显反光；
6. 用卡尺测量连续 10 个方格的跨度；
7. 水平和垂直方向各测量至少一次；
8. 使用实测平均方格尺寸运行标定脚本，不能直接填写 7.0 mm。

示例：

```text
10 个方格理论跨度：70.00 mm
水平实测跨度：69.86 mm
垂直实测跨度：69.92 mm
标定输入方格尺寸：(69.86 + 69.92) / 20 = 6.989 mm
```

如果水平与垂直方向的实测尺寸差异超过约 0.2%，应重新打印或检查打印机缩放。

### 4.3 靶标平面要求

标定靶表面必须与被测胶条表面处于相同高度。胶条通常有一定厚度，如果靶标平台比实际胶条上表面高或低 1～3 mm，严格来说会产生少量尺度偏差。

初期可以把棋盘格放在实际胶条同一工作平面上；若无法做到，应通过垫片补偿靶板厚度，并在标定记录中写清实际高度差。

## 5. 3D 打印固定件要求

### 5.1 结构

建议制作“相机支架 + 靶标平台”一体化底座：

- 相机光轴垂直靶面；
- 相机支架和靶标平台尽量平行；
- 高度可调，初始设计高度约 135 mm；
- 使用 M4 长圆孔、垫片或可换隔套微调高度；
- 相机固定孔与相机安装孔匹配，避免过载和滑牙；
- 靶标平台设置定位挡边，使棋盘格每次复位一致；
- 底座预留线缆应力释放结构；
- 打印件使用黑色哑光 PLA 或 PETG。

### 5.2 精度控制

3D 打印件存在收缩、层纹和装配误差，因此：

- 打印高度只作为粗定位；
- 必须通过实际图像调整高度；
- 不直接使用打印件的标称高度计算 `mm_per_px`；
- 锁紧后不能因线缆拉动改变相机姿态；
- 应用直角尺、水平仪或靶面边线检查光轴垂直度。

## 6. 采集前冻结相机参数

标定和验证期间必须固定以下参数：

| 参数 | 建议设置 |
|---|---|
| 分辨率 | 1440 x 1080 |
| 像素格式 | Mono8 |
| 自动曝光 | 关闭 |
| 自动增益 | 关闭 |
| 增益 | 初值为 0 dB |
| 曝光时间 | 根据白场和目标亮度固定 |
| 焦距 | 调清后锁紧 |
| 光圈 | 比较 F2.8 和 F4 后选定一个值 |
| 图像缩放 | 关闭 |
| 图像裁剪 | 关闭 |
| 保存格式 | PNG 或 BMP，禁止 JPEG |

MVS 只是采集和预览工具，保存的必须是原始分辨率无损图像。

调焦时重点看：

- 中心与四角是否同时清晰；
- 镜头边缘是否出现明显暗角；
- 黑白边界是否锐利；
- 棋盘格是否存在透视倾斜；
- 不同曝光下是否出现饱和。

锁定焦距和光圈后，在镜头环上做标记。记录相机序列号、镜头型号、光圈值、曝光时间、增益和相机到靶面的实际距离。

## 7. 采集标定图像

### 7.1 数量与位姿

共采集 25～30 张，建议使用 30 张并至少保留 25 张有效图：

| 位姿 | 建议数量 |
|---|---:|
| 中心正对靶面 | 3 |
| 靶标移动到四角 | 4 |
| 靶标移动到上下左右边缘 | 4 |
| 左右倾斜约 10～15° | 4 |
| 上下倾斜约 10～15° | 4 |
| 平面内旋转并组合不同位置 | 11 |

每张图应满足：

- 棋盘格完整可见；
- 内角点没有被画面边界裁掉；
- 黑白区域没有过曝；
- 没有运动模糊；
- 没有局部反光和阴影遮挡角点；
- 棋盘格尽量占据画面主要区域，但不要裁边。

### 7.2 目录和命名

原图放在被 Git 忽略的目录：

```text
data/
└─ raw/
   └─ calib/
      └─ 20261116_cb016/
         ├─ calib_001.png
         ├─ calib_002.png
         └─ ...
```

标定结果放在可版本管理的目录：

```text
data/
└─ calib/
   └─ 20261116_cb016.json
```

### 7.3 采集顺序建议

1. 拍中心直视图；
2. 把靶标依次移到四角和四边；
3. 绕水平轴倾斜；
4. 绕垂直轴倾斜；
5. 改变平面内旋转角；
6. 检查是否存在大量模糊或反光图，发现后立即重拍。

不要只移动一次靶标后连续拍多帧，应确保不同图像具有位姿变化。

## 8. 运行标定

假设打印靶内角点为 13 x 9，实测方格尺寸为 6.989 mm：

```powershell
py -3 scripts/calibrate_board.py `
  --images data/raw/calib/20261116_cb016 `
  --cols 13 `
  --rows 9 `
  --square-mm 6.989 `
  --out data/calib/20261116_cb016.json
```

注意：

- `--cols` 和 `--rows` 是内角点数量，不是黑白方块数量；
- 如果打印的是 13 x 9 个黑白方块，应输入 12 x 8；
- `--square-mm` 必须使用打印后实测值；
- 标定图不要缩放或裁剪；
- 相机、镜头、焦距、光圈或工作距离改变后必须重新标定。

### 8.1 结果检查

运行后检查：

1. `calib.rms` 总体重投影误差；
2. `calib.per_view_errors` 的条目数；
3. 每一张有效视图的单独误差；
4. `calib.K` 内参是否合理；
5. `calib.dist` 畸变参数是否合理；
6. `calib.mm_per_px` 是否与理论视野量级一致。

当前脚本会跳过未识别出棋盘格的图片。命令行输出的“参与标定的图像”是输入图片数，因此必须用 `per_view_errors` 的数量确认真正参与标定的图片数。

建议的工程初筛范围：

- 总体重投影 RMS：优先控制在 0.3～0.5 px；
- 单张视图误差明显高于其他视图时，优先检查模糊、反光、角点裁边和靶板翘曲；
- 不通过删除高误差图片来强行降低指标。删除前必须记录原因。

重投影误差只说明标定结果内部自洽，不能代替物理尺寸验证。

## 9. 独立验证

### 9.1 标定结果留出验证

从 30 张标定图中留出 5 张不参与标定，作为独立检查集。

验证内容：

- 棋盘格角点重投影；
- 图像四角与中心误差是否一致；
- 是否存在明显的径向或切向畸变残余。

当前 `scripts/calibrate_board.py` 还没有独立的留出验证流程，本轮可以先人工分开“标定集”和“验证集”目录；后续应补充自动化验证脚本。

### 9.2 已知宽度物理验证

准备 5、8、10、12、15 mm 左右的已知宽度试件，或使用游标卡尺实测真实胶条。要求：

- 试件表面高度与标定靶面一致；
- 游标卡尺每个位置重复测量 3 次并取均值；
- 每个试件至少在画面中心、四角和边缘各采集一次；
- 同一位置连续采集 3 帧，检查重复性；
- 不得使用理论宽度代替卡尺真值。

建议初期验收目标：

| 指标 | 初期目标 |
|---|---:|
| 固定位置重复性 | ≤ 0.2 mm |
| 同一试件不同位置的尺度偏差 | 约 ±0.2 mm |
| 宽度 MAE | ≤ 0.4 mm |
| 最大宽度误差 | ≤ 1.0 mm |

这些是工程初筛目标，不是论文原始指标。若边缘误差明显大于中心，应先处理去畸变、局部映射和镜头边缘清晰度问题。

## 10. 当前代码需要补齐的标定能力

当前 `algo/calib.py` 已经可以输出 `K`、`dist`、`H` 和平均 `mm_per_px`，但 `GlueInspector` 目前只使用单一平均 `mm_per_px`：

- 没有在量测前应用去畸变；
- 没有真正使用单应矩阵 `H`；
- `MappingTable` 尚未接入检测流水线；
- 输出结果尚未携带标定版本。

因此本轮分为两个层次：

### 10.1 第一层：完成初始真实尺度

- 生成并保存标定 JSON；
- 使用平均 `mm_per_px` 得到初始宽度；
- 只在中心和有限视野范围内验证；
- 记录边缘误差，不把第一层结果当作最终全视野结论。

### 10.2 第二层：正式量测前修正

进入正式 P1 报告前，代码至少需要：

1. 根据 `K` 和 `dist` 对图像或 ROI 去畸变；
2. 应用固定工作平面的单应映射，或按位置查询 `MappingTable`；
3. 将标定文件路径、标定版本和有效工作距离写入结果；
4. 增加独立验证脚本，报告角点重投影和已知宽度误差；
5. 对中心、边缘和四角分别统计误差。

在第二层完成前，可以运行算法和收集数据，但不能把边缘宽度结果作为正式精度指标。

## 11. 建议的五日执行安排

| 日期 | 工作 | 退出条件 |
|---|---|---|
| 第 1 天 | 打印棋盘格并粘板，制作和装配 3D 打印支架 | 靶面平整，相机和靶面平行，高度可调 |

如果第 3 天大量角点识别失败，不要继续增加算法复杂度，应先检查打印缩放、靶面平整度、曝光和焦距。

## 12. 记录与冻结

标定记录至少包含：

- 相机型号和序列号；
- 镜头型号、焦距、光圈和锁紧状态；
- 相机到被测物表面的距离；
- 靶标内角点数量；
- 打印方格实测尺寸；
- 靶板厚度和表面高度；
- MVS 分辨率、像素格式、曝光和增益；
- 环境光和后续红光光源状态；
- 标定日期和操作人；
- 标定 JSON 路径；
- 有效图片数量和误差统计；
- 未通过或删除图片的原因。

以下任一情况发生时必须重新标定：

- 相机或镜头被拆下、碰撞或松动；
- 焦距、光圈或工作距离改变；
- 镜头、靶面或相机法兰位置改变；
- 更换相机、镜头或标定靶；
- 几何标定与现场尺寸结果出现无法解释的系统偏差；
- 标定版本与检测结果无法对应。
