# 论文算法 vs 产品算法：对照说明

> 版本：2026-11-17
> 对照对象：
> 1. 《基于机器视觉的车身涂胶在线检测系统研究》（天津大学硕士学位论文，2022，96 页，下称**论文**）；
> 2. 《涂胶检测系统产品介绍（含智能检测）V3.3（水印版）》（易思维 ISV，30 页，下称**产品册**）。
>
> 说明：两份材料的性质不同——论文是可核查的算法研究，产品册是营销材料。本文只做"事实对照"，不把产品册的宣传语当作可复现指标；具体页码/章节均在文中标注。

---

## 1. 结论（先看这一段）

1. **两者不是同一个算法**，解决的是同一类问题（车身涂胶在线检测），硬件形态也高度相似（三相机 + 环形 LED 的圆形传感器）。
2. **论文 = 深度学习辅助 + 传统几何量测**：RPN 做胶条 RoI 定位，YOLOv3-5FL+SPP 做反光干扰检测，宽度靠"面积 ÷ 骨架长度 × 标定系数"。
3. **产品册 = 两条路线并存**：
   - **标准检测**：图像处理 + **示教信息**判断连续性/胶宽/位置，**不含深度学习**；
   - **智能检测（选配）**：**深度学习 CNN**（Backbone + Neck + 检测/坐标头），用大量标注图像训练，面向复杂背景与干扰场景。
4. **判据不同**：论文回答"如何用深度学习替代模板匹配/固定 RoI 并给出可核查精度"；产品回答"如何在产线上把检测做稳并卖出去"。因此不能简单说谁"更先进"。

## 2. 论文算法全景

| 环节 | 章节 | 做法 | 论文给出的结果 |
| --- | --- | --- | --- |
| 胶条 RoI 定位 | 3.1（3.1.1–3.1.4） | 简化 **RPN** 网络；K-means 生成 9 个先验框；改进定位损失（DIoU/CIoU）；改进 NMS（CIoU-NMS，阈值 0.5） | 平均 IoU **99%** |
| 反光干扰检测 | 3.2–3.3（3.3.1–3.3.4） | **YOLOv3-5FL**：5 层特征层；**嵌入 SPP**（4/2/1 多尺度池化）；15 个先验框 | 77 张反光样本检出 75 张（**97%**） |
| 预处理 | 4.1–4.2 | 小波硬阈值去噪（阈值按式 4-4）；Otsu/阈值分割对比；开闭运算修孔洞 | 定性对比（图 4-9/4-10） |
| 标定 | 4.3 | 视觉传感器快速标定：13×9 角点、4 mm 棋盘格、张正友式内参、逐视图重投影误差、两点比值映射 | 重投影误差表（表 4-2） |
| 宽度量测 | 4.4 | BFS 连通域面积；Zhang-Suen 骨架 + 图直径长度；**宽度 = 面积 ÷ 骨架长度 × 标定系数** | MAE **0.23 mm**、std **0.25 mm**、max **0.39 mm** |
| 缺陷判定 | 5.3.3 | RoI 数量 >1 判断断胶；双报警线与标准宽度比较；反光复判（提示调整而非直接判废） | 定性，过窄样本仅 3 条 |
| 系统性能 | 2.1/5.x | 视野 100 mm×80 mm、采集 30 fps、平均检测 **80 ms** | 满足 1 mm 精度要求 |

补充硬件（论文 2.2）：三台相机以 **120°** 夹角分布于圆形传感器内，USB-HUB 汇聚到工控机；红色 LED 灯板，24 V 机器人 IO 触发；明视野照明；软件分 PCIE 通信、图像检测、用户查询三个板块，共享内存交互。论文本身也有"示教"概念（2.2.2：读取示教过程选定的相机号）。

## 3. 产品册算法全景

产品册把检测拆成"标准检测"和"智能检测（选配）"两种能力（P10–P13）。

| 模式 | 页面依据 | 做法 |
| --- | --- | --- |
| **标准检测**（基础能力） | P13"工作原理" | ① 红色 LED 均匀照射 → ② 三相机 360° 无死角拍摄 → ③ 图像处理计算胶条位置与灰度信息 → ④ **利用示教信息**判断连续性、胶宽、位置 |
| **智能检测**（选配） | P11"训练/检测流程"、P12"抗干扰案例" | 深度学习 CNN：用标签 + 大量胶水图像训练；检测时 Input → Model → Output；网络结构为 Backbone + Neck + 多任务头（示意含 Score / Pose & BBox 分支）；宣称基于"5000 套系统数据、千万级图片"，支持持续迭代训练 |
| 软件能力 | P17"系统特点" | 报表统计（全车型/单车型）、支持双语界面、胶条宽度双报警线、不同曝光设置、支持自动示教、车型导入与工艺卡片对应 |

产品册给出的缺陷类型（P9–P10）：断胶（未出胶/气泡）、过宽/过窄、空白处有胶（多胶）、位置偏差、胶条连续性。

产品册**没有公开**：网络结构细节、损失函数、训练超参、检测精度数值、误报率、推理耗时。P11–P12 的示意图只能说明"使用深度学习做检测/坐标输出"，不能据此认定其架构等价于论文的 RPN 或 YOLOv3-5FL。

## 4. 逐项对比

| 维度 | 论文 | 产品册·标准检测 | 产品册·智能检测（选配） |
| --- | --- | --- | --- |
| RoI / 定位方式 | RPN 自动生成候选框 | 示教 + 图像处理定位 | CNN 输出检测/坐标（结构未公开） |
| 反光/干扰处理 | 单独训练 YOLOv3-5FL+SPP 检测反光区域，再复判 | 依赖光源与示教阈值 | 用大量复杂场景样本训练（焊点、孔洞、阴影、压胶反光、凹槽、板件混用、打磨件、低对比度） |
| 宽度测量 | 面积/骨架几何 + 标定映射 | 扫描线/灰度 + 示教阈值 | 推测由网络输出轮廓后几何计算（未公开） |
| 是否使用深度学习 | 是（定位 + 反光两个辅助模块） | **否** | 是（核心） |
| 数据依赖 | 自建数据集（论文未公开规模与来源） | 每车型一套示教图 | 千万级标注图、持续迭代 |
| 可解释性 | 强：每个环节可单独验证，误差可溯源 | 强：规则与阈值可读可调 | 弱：黑盒，出错难归因 |
| 换车型成本 | 改配方/阈值 + 补数据 | 重新示教 | 数据驱动，理论上更快 |
| 指标可核查性 | 有明确指标（99% / 97% / 0.23 mm） | 无公开指标 | 无公开指标（营销表述） |
| 硬件 | 三相机 120°、红色 LED、24 V IO 触发、FOV 100×80 mm、1/3" 靶面 | 圆形传感器：1K/2K sensor，内径 45/65 mm，三种工作距离型号（P14–P15） | 同左 |
| 实时性 | 30 fps、80 ms 平均 | 不占生产节拍（P10） | 需额外算力（产品册未给耗时） |
| 部署形态 | 工控机 + 板卡 + 三个软件板块 | 传感器 + 工控机软件 | 同左（模型可能需 GPU） |

## 5. 相同点（为什么容易混为一谈）

1. **硬件形态几乎一致**：三相机 120° 分布、圆形传感器、红色 LED 照明、机器人 IO 触发、USB 汇聚；
2. **缺陷定义一致**：断胶、过宽/过窄、多胶、位置偏差；
3. **都采用"图像处理 + 几何量测"打底**，都强调实时、不占节拍、存图可追溯；
4. **论文的批评对象正是产品的标准路线**：论文 3.1 开头明确说"模板匹配或固定 RoI 法因胶条偏移导致检测误差大"，而产品标准检测正是示教/模板式路线——这解释了论文为什么要引入 RPN 与 YOLO。

---

## 6. 差异的本质

| 问题性质 | 论文 | 产品 |
| --- | --- | --- |
| "胶条宽度是多少"（测量） | 几何 + 标定，误差可溯源 | 标准模式同样用几何/灰度；智能模式交给网络 |
| "有没有断胶/反光/偏移"（检测） | RPN + YOLO（深度学习） | 智能检测（深度学习） |
| "怎么在产线落地"（工程） | 不在论文范围 | 示教、报表、车型导入、双报警线、迭代机制 |

即：**论文把深度学习用在"定位与抗干扰"，把测量留给几何；产品把深度学习做成"可选的整体替代"，把测量也交给数据。** 前者更可核查，后者更"上限高但成本高"。

## 7. 选型建议

| 场景/约束 | 建议 |
| --- | --- |
| 学术复现、要与论文指标对照、数据量有限 | **论文路线** |
| 需要误差可溯源（宽度 ±0.1 mm 级）、要通过标定/验收 | **论文路线（几何量测）** |
| 产线背景复杂（焊点、阴影、反光、低对比度）、车型多、可投入标注与算力 | **产品智能检测路线** |
| 现场工程师要能快速调阈值、成本敏感 | **产品标准示教路线** |
| 长期产品化 | 混合架构：几何量测保精度 + DL 只做难样本辅助（见 §8） |

## 8. 对本项目的启示

1. **复现依据只能是论文**：产品册无结构、无损失、无指标，不能作为实现或验收依据；
2. **产品册用于需求对标**：示教/配方、双报警线、车型导入、报表与追溯，是我们上位机已部分实现的工程能力（见 `docs/host-software-architecture.md`）；
3. **混合架构是合理演进**：传统链路已能在 Rust 上跑到 p50 7.6 ms（本项目实测，非论文指标），DL 仅作为 RoI/反光/低对比度场景的辅助模块，与论文分工一致；
4. **评测口径必须分开**：论文的 99%/97%/0.23 mm 与产品宣传语不在同一口径下，任何"产品更准/更先进"的结论都需要同场景实测数据支撑。

## 9. 证据与局限

- 论文页码引用基于本地 PDF 文本抽取（96 页，可检索）；产品册文本层为 GBK 编码字体、无法直接复制，本文所引内容为逐页渲染读图（P9–P17）所得；
- 产品册为营销材料，本文对其"智能检测"的描述严格限定在图示与文字可支持的范围，未推测其网络结构；
- 论文指标为作者自建数据上的结果，不可直接外推到产线；
- 二者均未公开可复现的训练配置/权重，因此本对照是"结构与方法"层面的，不是"同数据性能"层面的。
